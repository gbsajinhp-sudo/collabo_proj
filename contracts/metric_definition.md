# Metric Contract

## 책임자

human2

## 지표

| 지표 | 정의 |
|---|---|
| 집적도 | 1㎢ 또는 H3 격자당 사업체 수 |
| 특화도 | 경기도 평균과 비교한 선택 산업의 지역 특화계수 LQ |
| 증감률 | 비교 가능한 이전 조사연도 대비 사업체 변화율 |

## 필수 규칙

- KSIC 10차와 11차 전환 구간은 직접 증감 비교하지 않는다.
- 분모가 0이거나 비교가 성립하지 않으면 임의의 0으로 치환하지 않는다.
- 지도 요청 시 전체 원자료를 재계산하지 않고 사전집계 결과를 사용한다.
- H3 해상도, 행정구역 수준, 산업분류 수준별 계산 기준을 테스트로 고정한다.

세부 SQL과 검증 기대값은 기존 최종 엔진을 이관할 때 확정한다.
