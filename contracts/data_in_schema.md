# DATA_in Contract

## 책임자

human1

## 목적

주소 정규화, 좌표, 행정구역, 조사연도별 KSIC를 결합한 분석 입력을 human2에게 제공한다.

## 고정 기준

- 분석연도: 2019-2024
- 산업분류: 2019-2023년 KSIC 10차, 2024년 KSIC 11차
- 주소: 조사 당시 주소값 보존
- 지도 경계: 2025-12-31 기준
- 좌표계: 웹 지도에서 사용할 WGS84 경위도
- 상세 테이블 기준 행 수: 8,153,597

최종 컬럼, 자료형, NULL 허용, 고유키 및 품질 임계치는 기존 검증 결과를 이관할 때 확정한다.
